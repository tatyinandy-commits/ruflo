Мы с тобой создаём личную коллекцию инструментов для работы — репозиторий `best`. Это курируемый набор самых полезных инструментов: Claude Code скиллы/агенты, MCP-интеграции, база знаний/промпты и CLI/dev-скрипты.

Формат проекта: нейтральный/смешанный — всё как обычные файлы (markdown / JSON / YAML / bash), совместимые с форматом `.claude/` Claude Code, чтобы любой элемент можно было скопировать в другой проект и сразу использовать.

Структура, которую нужно создать:

best/
├── README.md              # главный индекс
├── CONTRIBUTING.md        # правила добавления элементов
├── catalog.json           # машиночитаемый реестр всего
├── skills/                # Claude Code скиллы (папка/SKILL.md с frontmatter)
├── agents/                # агенты (.md с frontmatter name + description)
├── commands/              # slash-команды (.md)
├── hooks/                 # хуки и автоматизация (JSON-фрагменты + скрипты)
├── mcp/                   # MCP-конфиги и обёртки
├── prompts/               # промпты, шпаргалки, заметки
├── scripts/               # CLI / dev-утилиты (bash/python)
└── docs/                  # best practices, заметки

Принципы:
- Каждый элемент самодостаточен — работает после копирования без правок
- Только проверенное, не черновики «на будущее»
- Секреты только через переменные окружения, никогда в файлах

Первая задача: создай полную структуру проекта с шаблонами для каждого типа элемента и скриптом scripts/new-item.sh, который скаффолдит новый элемент (skill | agent | command | prompt) из шаблона. Коммить и пушь в ветку main.
