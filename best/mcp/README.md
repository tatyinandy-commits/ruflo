# mcp/

MCP-интеграции: переиспользуемые конфиги серверов и обёртки.

## Формат

MCP-серверы описываются в `.mcp.json` (или через `claude mcp add`). Здесь храним
проверенные конфигурации, чтобы быстро подключать в новых проектах.

```json
{
  "mcpServers": {
    "my-server": {
      "command": "npx",
      "args": ["-y", "@scope/my-mcp-server"],
      "env": { "API_KEY": "${MY_API_KEY}" }
    }
  }
}
```

## Использование

```bash
# вариант 1: добавить через CLI
claude mcp add my-server npx -y @scope/my-mcp-server

# вариант 2: скопировать блок в .mcp.json проекта
```

> ⚠️ Никогда не коммить реальные ключи. Используй переменные окружения (`${VAR}`)
> и подставляй значения из `.env` при запуске.

См. пример [`mcp.example.json`](./mcp.example.json).
