# Best practices

Заметки и принципы работы, которые собираем по ходу дела.

## Организация коллекции

- Добавляй только то, что реально использовал хотя бы раз.
- Один элемент — одна ответственность.
- Имя в `kebab-case`, понятное без открытия файла.

## Claude Code

- Скиллы подбираются по `description` — пиши его конкретно, с триггерами «когда применять».
- Агенты — по `description`; держи системный промпт коротким и фокусным.
- Секреты — только через переменные окружения, никогда в файлах.

## Будет дополняться

Сюда складываем выводы из реальной работы.
