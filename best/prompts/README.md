# prompts/

База знаний: промпты, шпаргалки, заметки, best practices. Свободный markdown.

## Формат

Один файл — одна тема. Структура внутри:

```markdown
# Тема

## Когда использовать
...

## Промпт
> сам промпт в цитате или блоке кода

## Заметки
- что работает, что нет
```

## Создать новый

```bash
best/scripts/new-item.sh prompt my-prompt
```

См. шаблон [`_template.md`](./_template.md).
